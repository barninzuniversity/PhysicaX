# PhysicaX

Computational physics platform blueprint and reference pack.

This repository contains the structured product blueprint, formula reference, and site for PhysicaX — a modular platform for simulation, visualization, education, and research workflows.

## Contents

- `index.html` / `styles.css` / `script.js` — blueprint site
- `PhysicaX_Formula_Reference.md` — canonical formula pack
- Guide extraction artifacts in this tree for traceability

## Status

This repo currently hosts the specification and reference pack. Implementation work is planned in phased milestones tracked in `ROADMAP.md`.

## Quick Start

Option A: run the setup installer first

1. Double-click `install.bat`
2. After it finishes, run `npm start`

Option B: manual setup

1. Install Node.js from https://nodejs.org
2. Run `npm install`
3. Run `npm start`

To build a Windows installer: `npm run build`
